# zig-tool Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `gitlab.com/devnw/zig/zig-tool` as the single source of truth for the diamond-deps tooling (a pre-commit remote hook + a uvx-run cascade CLI), then migrate all 54 devnw/zig + geode repos to consume it and delete their vendored copies.

**Architecture:** A stdlib-only Python package `zig_tool` that is also a pre-commit hook repo. The `detect-diamond-deps` gate ships as a `language: python` pre-commit hook; the `sync-diamond` cascade ships as a `zig-tool` CLI run via `uvx`. Consuming repos reference `zig-tool` by URL + `rev`; `pre-commit autoupdate` pulls latest. The migration is a mechanical all-at-once sweep with per-repo push-failure reporting.

**Tech Stack:** Python 3.11+ (stdlib only at runtime), `pyproject.toml` (PEP 621), pytest, ruff, pre-commit, glab, git, uv/uvx.

**Reference spec:** `docs/superpowers/specs/2026-06-12-zig-tool-design.md`

**Canonical source files to port** (from this repo):

- `scripts/detect_diamond_deps.py` — `main(argv)->int` (0 clean / 1 diamond / 2 IO-or-cache-miss); pure helpers `_strip_comments`, `_find_dependencies_block`, `_parse_dep_entries`, `_zon_path_for_hash`, `collect_transitive`, `find_diamonds`.
- `scripts/sync_diamond_deps.py` — `main(argv)->int`, `cascade(...)`, helpers `rewrite_pin(text,name,url_with_ref,pkg_hash)->(text,int)`, `latest_patch_tag`, `next_free_patch_tag`, `remote_tag_exists`, `zon_direct_deps`, `zig_pkg_hash`, `refresh_cache`, `diamond_clean`, dataclasses `Repo`/`Bumped`, `SEMVER_TAG_RE`; currently does `import detect_diamond_deps as ddd`.
- `scripts/sync_diamond_deps.sh` — thin wrapper (will NOT be ported; replaced by `uvx`).

**Working directory:** Build the package under a fresh local path `~/src/gl/gitlab.com/devnw/zig/zig-tool` (the eventual repo clone). All Task 1-7 commands run there unless stated otherwise.

```python
def hook_main(argv: list[str] | None = None) -> int:
    """pre-commit entry point. The cache-not-populated / IO case (main()==2)
    must NOT block a commit — it means deps aren't fetched yet — so map it to
    a soft pass with a notice. A real diamond (==1) still fails the commit."""
    import sys

    rc = main(argv if argv is not None else sys.argv)
    if rc == 2:
        print(
            "detect-diamond-deps: cache not populated; skipping "
            "(run 'zig build --fetch')",
            file=sys.stderr,
        )
        return 0
    return rc


if __name__ == "__main__":
    import sys

    sys.exit(hook_main(sys.argv))
```

- [ ] **Step 1: Write `src/zig_tool/cli.py`**

```python
"""`zig-tool` umbrella CLI. Subcommands dispatch to the tool modules.

Each tool keeps its own argv contract; the CLI forwards the remaining args
through unchanged so `zig-tool sync-diamond --cascade --apply ...` behaves
exactly like the standalone cascade.
"""

from __future__ import annotations

import sys

from . import detect_diamond_deps, sync_diamond_deps


def main(argv: list[str] | None = None) -> int:
    argv = list(sys.argv if argv is None else argv)
    if len(argv) < 2 or argv[1] in ("-h", "--help"):
        print("usage: zig-tool {detect-diamond,sync-diamond} [args...]", file=sys.stderr)
        return 0 if len(argv) >= 2 else 2
    sub, rest = argv[1], argv[2:]
    if sub == "detect-diamond":
        return detect_diamond_deps.hook_main(["detect-diamond", *rest])
    if sub == "sync-diamond":
        return sync_diamond_deps.main(["sync-diamond", *rest])
    print(f"zig-tool: unknown subcommand {sub!r}", file=sys.stderr)
    return 2


if __name__ == "__main__":
    sys.exit(main())
```

- [ ] **Step 1: Write `migrate/migrate_repo.py`**

```python
"""Rewire one repo's .pre-commit-config.yaml to consume detect-diamond-deps
from zig-tool, and delete its vendored diamond scripts. Idempotent; pure file
edits (no git). Uses ruamel.yaml to preserve comments/formatting."""

from __future__ import annotations

import sys
from pathlib import Path

from ruamel.yaml import YAML

ZIG_TOOL_REPO = "https://gitlab.com/devnw/zig/zig-tool"
ZIG_TOOL_REV = "v0.1.0"
VENDORED = (
    "scripts/detect_diamond_deps.py",
    "scripts/sync_diamond_deps.py",
    "scripts/sync_diamond_deps.sh",
)


def migrate(repo_root: Path) -> dict:
    cfg = repo_root / ".pre-commit-config.yaml"
    result = {"config_changed": False, "deleted": [], "already": False}
    if not cfg.exists():
        result["error"] = "no .pre-commit-config.yaml"
        return result

    yaml = YAML()
    yaml.preserve_quotes = True
    data = yaml.load(cfg.read_text())
    repos = data.get("repos", [])

    # Already migrated?
    if any(r.get("repo") == ZIG_TOOL_REPO for r in repos):
        result["already"] = True
    else:
        # Remove the local detect-diamond-deps hook.
        removed = False
        for r in repos:
            hooks = r.get("hooks", [])
            kept = [h for h in hooks if h.get("id") != "detect-diamond-deps"]
            if len(kept) != len(hooks):
                r["hooks"] = kept
                removed = True
        # Drop now-empty local repo blocks.
        data["repos"] = [r for r in repos if r.get("hooks")]
        if removed:
            entry = {
                "repo": ZIG_TOOL_REPO,
                "rev": ZIG_TOOL_REV,
                "hooks": [{"id": "detect-diamond-deps"}],
            }
            data["repos"].append(entry)
            with cfg.open("w") as fh:
                yaml.dump(data, fh)
            result["config_changed"] = True

    for rel in VENDORED:
        f = repo_root / rel
        if f.exists():
            f.unlink()
            result["deleted"].append(rel)
    return result


if __name__ == "__main__":
    import json

    print(json.dumps(migrate(Path(sys.argv[1]).resolve()), indent=2))
```
